# AI-Productivity-Assistant - WorkSmart AI
By: Khanyisile Gubuza 

### Project Overview
WorkSmart AI is an AI-powered workplace productivity assistant designed to help professionals automate repetitive tasks like drafting emails, summarizing meetings, and planning daily tasks. The goal is to save time and improve efficiency.

### Problem Statement
Professionals across industries spend significant time on repetitive tasks such as drafting emails (28% of workweek), summarizing information, and planning schedules. This leads to burnout and reduced productivity.

### Features Implemented - Exceeding Minimum Requirement
Project required at least 3 features. I implemented all 5 features to demonstrate full capability:

1.  **Smart Email Generator [CORE - Fully Functional]**: Generates professional emails with tone control (formal/friendly/persuasive) and audience adaptation.

2.  **Meeting Notes Summarizer [CORE - Fully Functional]**: Summarizes long notes, extracts key points, decisions, and action items with deadlines.

3.  **AI Task Planner / Scheduler [CORE - Fully Functional]**: Generates daily/weekly schedules and prioritizes using Eisenhower matrix.

4.  **AI Research Assistant [BONUS - Implemented]**: Summarizes topics/articles and provides insights and recommendations.

5.  **AI Chatbot Interface [BONUS - Implemented]**: Interactive workplace assistant for general queries and prompt handling.

Compliance: 100% - All 5 features built into ONE integrated dashboard with sidebar navigation as required.
